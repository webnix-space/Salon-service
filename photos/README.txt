Put salon photos in this folder. File names must match salon.config.json:

  hero.jpg      wide photo of a salon interior (chairs, mirrors)
  salon-1.jpg   hair colouring
  salon-2.jpg   haircut / styling
  salon-3.jpg   bridal makeup
  salon-4.jpg   facial / skin treatment
  salon-5.jpg   manicure / nails
  salon-6.jpg   hair wash station or product shelf

Any missing file is skipped automatically. Keep each file under 300 KB (about 1400 px wide, JPEG quality 75-80).
While the photos are stock, keep "demoPhotos": true in salon.config.json. Every photo then shows a "Sample photo" tag
and the gallery explains they will be replaced. Set it to false when you swap in the salon's real photos.
